## What?
This project is dedicated to understanding how to predict future stock prices using ai.
I am in the exploratory phase at the moment. Using Jupyter notebooks to create a valid dataset.

DATA:
EUR/GBP OHLC price values for a time period from 2003-2020
Moon Phase data for same period

## Why?
I want to explore the relationship between forex markets and astrological patterns and other alternative data.
I want to see if I can reach my own conclusion about wether or not their is a useful relationship.
I will backtest my ai powered model on this data to create a trading strategy and evaluate its performance.
